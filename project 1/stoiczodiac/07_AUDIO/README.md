# Audio Library

| Folder | Purpose |
|--------|---------|
| `music/royalty_free/` | Licensed background music tracks (Epidemic Sound, Uppbeat, etc.) |
| `music/original/` | Original compositions / custom tracks |
| `sound_effects/` | SFX — transitions, swooshes, clicks, ambient sounds |
| `voiceover_audio/` | Recorded voiceover audio files (WAV, MP3) |
| `voiceover_scripts/` | Written scripts (see `reel_voiceover_bank.md`) |

> 🔗 Scripts live in `voiceover_scripts/` — audio recordings go in `voiceover_audio/`.

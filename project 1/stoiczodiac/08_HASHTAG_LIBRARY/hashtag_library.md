## 📊 Hashtag Audit Checklist (Weekly)

```markdown
[ ] Display Purposes check: Tags still active?
[ ] Remove tags that Instagram flagged as "banned"
[ ] Replace 2–3 underperforming tags
[ ] Check competitor tags (top 3 accounts)
[ ] Add 1 new trending tag per week
[ ] Track which tags drive saves vs. likes vs. follows
[ ] Rotate branded tags every 2 weeks
```

## 🚫 Tags to Avoid

- #followforfollow, #like4like (shadowban risk)
- #stoic (already in use — add context)
- Tags over 1M posts with no niche relevance (low engagement per post)
- Any tag that's been spam-reported in your niche (check Display Purposes)

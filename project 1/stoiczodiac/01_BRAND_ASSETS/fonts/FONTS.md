# Font Setup — Stoic Zodiac

## Required Fonts (Google Fonts — free)

All three are available from Google Fonts at no cost.

| Role | Font | Weight/Style | Download Link | Canva Name |
|------|------|-------------|---------------|------------|
| **Headlines** | Cormorant Garamond | Bold 700, Regular 400 | https://fonts.google.com/specimen/Cormorant+Garamond | Cormorant Garamond |
| **Body** | Raleway | Light 300, Regular 400 | https://fonts.google.com/specimen/Raleway | Raleway |
| **Quotes** | Playfair Display | Italic 400 | https://fonts.google.com/specimen/Playfair+Display | Playfair Display |

## Fallback Stack

```
font-family: 'Cormorant Garamond', Georgia, serif;
font-family: 'Raleway', Helvetica, Arial, sans-serif;
font-family: 'Playfair Display', Georgia, 'Times New Roman', serif;
```

## Where to Use

| Element | Font | Size | Style |
|---------|------|------|-------|
| Quote text (cards) | Playfair Display Italic | 48–64pt | Italic, Gold |
| Sign label | Cormorant Garamond | 36pt | Bold, sign color |
| Philosopher name | Raleway | 20pt | Light, White |
| Body text | Raleway | 16–18pt | Regular, White |
| CTA / Headlines | Cormorant Garamond | 24pt | Bold, Gold |

## Installation (for local design work)

1. Visit each Google Fonts link above
2. Click **Download family** → save `.ttf` files to this folder
3. On Windows: right-click each `.ttf` → **Install**
4. Fonts will be available in Canva, CapCut, and all design tools

## For Canva

Canva has all three fonts built-in — no installation needed. Search for them in the text tools panel.

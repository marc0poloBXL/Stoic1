# Brand Assets

| Folder | Purpose |
|--------|---------|
| `logos/` | Logo files — PNG (transparent), SVG, favicon variants |
| `fonts/` | Licensed brand typefaces (TTF, OTF, WOFF2) |
| `colors/` | Color palette files (ASE, CSS variables, hex references) |
| `graphics/` | Brand elements — patterns, badges, watermarks, dividers |

> 📄 See `brand_guidelines.md` for usage rules.

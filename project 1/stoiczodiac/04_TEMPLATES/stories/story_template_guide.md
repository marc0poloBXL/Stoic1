# Story Template Guide — Stoic Wisdom × Zodiac Signs

**Format**: 1080×1920 (9:16 vertical)
**Tool**: Canva (free tier)
**Style**: Dark, minimal, interactive — designed for quick daily engagement

---

## Story Templates

### Template S1 — Daily Stoic Prompt (Basic)

**Purpose**: Daily thought-provoker. Posted every day.

| Layer | Position | Content |
|-------|----------|---------|
| Background | Full canvas | Image (marble, stars, or abstract dark) with 60% dark overlay |
| Sign badge | Top-left | `[symbol] Sign Name` — 20pt, sign accent color |
| Label | Top-center | "Today's Stoic Prompt" — Raleway 14pt, Gold `#D4AF37` |
| Prompt text | Center | One line — 42pt, Playfair Display, White `#F5F5F5` |
| Reflection cue | Below prompt | "Reflect on this today." — Raleway 16pt italic, Bronze `#C9A96E` |
| CTA | Bottom | "@stoiczodiac" — 12pt, opacity 60% |

**Canva Creation:**
1. New design → 1080×1920 px
2. Background: Dark image (Pexels: "marble", "stars") + transparency overlay
3. Text layer: Prompt (Playfair, 42pt, centered)
4. Label: Raleway, 14pt, gold, top
5. **Save as template** → "Story — Daily Prompt"

### Template S2 — Quick Poll (Interactive)

**Purpose**: Engagement poll — 1 question, 2 options. Posted 2×/week.

| Layer | Position | Content |
|-------|----------|---------|
| Background | Full canvas | `#0A0A0A` + marble texture overlay at 8% opacity |
| Poll question | Center-top | "What's your take?" — Cormorant Garamond 28pt, White |
| Option A | Middle-left | Pill button — Raleway 18pt, Gold border, 40% wide |
| Option B | Middle-right | Pill button — Raleway 18pt, Gold border, 40% wide |
| Sign match | Bottom | "♈ Aries, this one's for you." — 14pt, sign color |

**Canva Creation:**
1. New design → 1080×1920 px
2. Background: `#0A0A0A` with marble filter
3. Text: Question (center top, safe zone)
4. Elements: "Rounded rectangle" × 2 → set border to Gold `#D4AF37`, fill transparent
5. Text inside each pill: A) / B) options
6. **Save as template** → "Story — Quick Poll"
7. **In Instagram**: Add the Poll sticker → type your options over the pill buttons

**Poll Ideas (pre-written):**
- "Which rules your decisions? A) Logic  B) Emotion"
- "Your stoic style? A) Marcus Aurelius  B) Seneca"
- "Morning ritual? A) Journal  B) Meditate"
- "Biggest distraction? A) Phone  B) People"
- "Your element? A) Fire  B) Water | C) Earth  D) Air"

### Template S3 — "This or That" Quiz (Interactive)

**Purpose**: Sign-based personality engagement. Posted 1×/week.

| Layer | Position | Content |
|-------|----------|---------|
| Background | Full canvas | `#1A1A2E` + subtle texture |
| Quiz label | Top | "STOIC QUIZ" — Raleway 12pt, Gold, letter-spacing 3 |
| Question | Top-center | "Which Stoic philosopher matches your energy?" — 22pt, White |
| This card | Left (30%) | Image placeholder + "A) Marcus" | 
| Or divider | Center | "OR" — Gold, small, vertical |
| That card | Right (30%) | Image placeholder + "B) Seneca" |
| CTA | Bottom | "Reply with A or B!" — 16pt, Bronze, italic |

**Canva Creation:**
1. New design → 1080×1920 px
2. Two card frames: Rounded rectangles (30% width each, centered left/right)
3. Image placeholder inside each + name below
4. Center "OR" text
5. **Save as template** → "Story — This or That"

**Quiz Topics:**
1. "Which Stoic matches your energy?" — A) Marcus (Disciplined) / B) Seneca (Reflective)
2. "Your stoic superpower?" — A) Focus / B) Resilience
3. "Which sign energy today?" — A) Fire sign / B) Water sign
4. "Your ideal morning?" — A) Silence / B) Action
5. "Response to chaos?" — A) Pause / B) Act

### Template S4 — Quote Engagement (Interactive)

| Large quote mark | Top center | Decorative `"` — 72pt, Gold, opacity 20% |
| Quote | Center | 2-line quote — Playfair Display 28pt, White |
| Attribution | Below quote | "— Seneca" — Raleway 14pt, Gold |
| Question | Bottom | "Tag someone who needs to hear this." — 14pt, italic, Bronze |
| CTA | Bottom | "@stoiczodiac" — 11pt, opacity 50% |

**Canva Creation:**
1. New design → 1080×1920 px
2. Quote mark element (use `svg_assets/large_quote_mark.svg` or Canva text)
3. Quote text centered in safe zone
4. Attribution + engagement prompt below
5. **Save as template** → "Story — Quote Engagement"

### Template S6 — Engagement Question (High Interaction)

**Purpose**: Open-ended question to drive DMs and comments. Posted 1×/week.

| Layer | Position | Content |
|-------|----------|---------|
| Background | Full canvas | Sign-color gradient (subtle, left-to-right) on dark base |

**Canva Creation:**
1. New design → 1080×1920 px
2. Background: `#0A0A0A` with subtle color wash for the sign of the day
3. Question text centered
4. **Save as template** → "Story — Journal Prompt"

**Pre-written Questions (rotate daily):**

- "What's one thing that went right today?"

## ⚡ Batch Production (30 min → 7 stories)

```
[ ] 0:00–0:05 — Open 6 story templates, duplicate each as needed
[ ] 0:05–0:15 — Fill in daily content from ChatGPT output
[ ] 0:15–0:22 — Adjust colors per sign, check text fit
[ ] 0:22–0:28 — Preview on mobile (text too small?)
[ ] 0:28–0:30 — Export as PNGs → Name: story_[type]_[YYYYMMDD].png
```

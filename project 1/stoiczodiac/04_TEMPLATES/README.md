# Templates

Modèles Canva + assets SVG réutilisables pour les posts.

## Fichiers

- `canva_setup_guide.md` — kit de marque Canva et 3 templates.
- `canva-app/` — app Canva Dev (React + Express).
- `carousels/`, `reels/`, `stories/`, `svg_assets/` — templates par format.

## Usage

Ouvrir un template, dupliquer, remplacer le contenu, exporter en PNG.

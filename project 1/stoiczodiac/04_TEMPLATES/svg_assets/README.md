# SVG Design Assets — Stoic Wisdom × Zodiac Signs

**Location**: `04_TEMPLATES/svg_assets/`
**Purpose**: Reusable vector templates for Canva upload — decorative frames, dividers, and brand elements.

---

## How to Use in Canva

1. Open Canva → any design (1080×1080 quote card, 1080×1920 story, etc.)
2. **Upload** → Select the SVG file → Drag onto canvas
3. Position and resize as needed
4. SVG elements have transparent backgrounds — they layer over your existing design

## Batch Production Tip

In Canva, upload the SVGs once to your Brand Kit. Then:

1. **Quote cards**: `quote_card_frame.svg` as base layer → add text on top
2. **Carousels**: `carousel_page_frame.svg` as base → duplicate per page → add content
3. **Stories**: `story_frame.svg` as overlay → adjust text to fit safe zone
4. **Dividers**: `gold_divider.svg` between sections in carousels

---

## Canva Animation Tips

- **Fade in** elements for subtle entrances
- **Typewriter** effect for quote text appearing line by line
- **Rise** animation for section titles
- Set all animations to **slow** (3-4 seconds) for the stoic, deliberate feel

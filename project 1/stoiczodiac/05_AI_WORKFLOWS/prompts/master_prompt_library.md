## 📝 Prompt 1: Daily Quote Generator

**Purpose**: Generate 7 days of sign-specific stoic quotes at once  
**Tool**: ChatGPT (GPT-3.5 free)

```
You are a content writer for a Stoic philosophy × zodiac signs Instagram page.

Generate 7 daily quote posts — one for each day of the week — following this format:

Today's date: [DATE]
Theme for the week: [e.g., "Resilience"]

For each day:
1. Day of week + date
2. Zodiac sign (rotate through all 12 over the month)
3. A Stoic philosopher (Marcus Aurelius, Seneca, Epictetus, Zeno, or Musonius Rufus)
4. A quote from that philosopher that resonates with that sign's archetype
5. A 2-3 sentence application of the quote to that sign's strengths and weaknesses
6. A one-sentence challenge ("Today, [sign]...")
7. 5 hashtags

Style rules:
- Use "you" — direct address
- Never change the quote — attribute it correctly
- Application must be practical, not abstract
- Keep total post under 300 characters
- Match the sign's energy (fiery for Aries, grounded for Taurus, etc.)

Generate all 7 now.
```

## 💡 Pro Tips

1. **Save these prompts** in a text file — reuse weekly
2. **Prompt chaining**: Run Prompt 1 → take output → run Prompt 5 with that output
3. **Batch generation**: Run 4 prompts at once (ChatGPT allows multiple tabs)
4. **Tweak per sign**: Keep a running doc of what resonates per sign and iterate
5. **Temperature setting**: Default ChatGPT temp works fine — if output is too generic, add "be more specific about [SIGN]'s traits"

## 📈 Key Metrics Dashboard

Track these 5 numbers every week:

```
📈 Growth Rate:      [ ]% (Target: 10%+ weekly)
❤️ Engagement Rate:  [ ]% (Target: 5%+)
💾 Save Rate:        [ ]% (Target: 3%+)
🎬 Reel View Rate:  [ ]% (Target: 30%+)
💬 DM Rate:          [ ]% (Target: 1%+)
```

### Formula Reference
```
Growth Rate = (New Followers / Start Followers) × 100
Engagement Rate = ((Likes + Comments + Saves + Shares) / Reach) × 100
Save Rate = (Saves / Reach) × 100
Reel View Rate = (Views / Accounts Reached) × 100
DM Rate = (DM Conversations / Followers) × 100
```

---

## 🚩 Red Flags to Watch

| Issue | Signal | Action |
|-------|--------|--------|
| Shadowban | Reach drops 50%+ in 24h | Remove hashtags, post 24h later |
| Content fatigue | Engagement drops 3 weeks straight | Change format, try new angle |
| Wrong audience | Followers but no engagement | Audit hashtags, improve content |
| Overposting | Drop-off in story views | Reduce stories to 3/day |
| Burnout | Skipping posting days | Use batch creation day |

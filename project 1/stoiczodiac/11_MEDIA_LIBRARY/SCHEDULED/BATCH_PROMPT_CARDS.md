# ⚡ Batch Prompt Cards

Quick-copy prompts for your Sunday batch session.

---

## 🃏 Card 1: Daily Quotes (Prompt 1)

```
You are a content writer for a Stoic philosophy × zodiac signs Instagram page.

Generate 7 daily quote posts — one for each day of the week — following this format:

Theme for the week: [WEEK THEME]

For each day:
1. Day of week + date
2. Zodiac sign
3. A Stoic philosopher
4. A quote from that philosopher that resonates with that sign's archetype
5. A 2-3 sentence application of the quote to that sign's strengths and weaknesses
6. A one-sentence challenge ("Today, [sign]...")
7. 5 hashtags

Style rules:
- Use "you" — direct address
- Never change the quote — attribute it correctly
- Application must be practical, not abstract
- Keep total post under 300 characters
- Match the sign's energy

Sign rotation this week:
→ See your WEEKLY_BATCH_BRIEF.md for signs + philosophers
```

## 🃏 Card 2: Reel Voiceover (Prompt 3)

```
Write a 20-25 second voiceover script for an Instagram Reel about [SIGN NAME].

The Reel shows zen visuals (nature, marble statues, candles, stars).

Script structure:
[0:00-0:02] Hook: "[SIGN], listen."
[0:02-0:15] The wisdom: A stoic quote, adapted to be spoken naturally, followed by 1 sentence of meaning.
[0:15-0:20] Application: How this applies to [SIGN]'s life today.
[0:20-0:25] CTA: "Follow @stoiczodiac for your sign's daily wisdom."

Tone: Calm, authoritative, warm.
```

## 🃏 Card 3: Captions (Prompt 5)

```
Write an Instagram caption for a [SIGN] post about [QUOTE].

Caption structure:
[1] Hook (1 line): "♈ [SIGN] — [compelling hook]"
[2] Quote (1-2 lines): "[QUOTE]" — [PHILOSOPHER]
[3] Application (2-3 lines): Specific to [SIGN]'s personality
[4] Challenge (1 line): "Today: [one actionable challenge]"
[5] CTA (1 line): "Save this. Follow @stoiczodiac for daily wisdom."
[6] Hashtags (10-12)

Tone: Direct, warm, wise.
```

## 🃏 Card 4: Engagement Comments (Prompt 10)

```
Generate 20 engagement comments for a Stoic × Zodiac Instagram page to leave on other accounts in the niche.

Categories (5 each):
- Stoic/philosophy posts
- Astrology/zodiac posts
- Self-improvement posts
- Meditation/mindfulness posts

Each comment should be:
- 1-2 sentences max
- Add value (question, insight, or compliment)
- NOT promotional (no "check my page")
- Natural and conversational
```

## 🃏 Card 5: Weekly Forecast (Prompt 4)

Theme for the week: [THEME]

Write a 10-slide weekly forecast carousel.

Slide 1: Title — "The Stoic Forecast: [DATES]"

  - Fire signs (Aries, Leo, Sagittarius): [shared stoic advice]
